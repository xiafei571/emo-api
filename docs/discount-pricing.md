# 模型广场价格

广场显示美元/百万 tokens 单价（按次模型为美元/请求），不叠加充值兑换比例。展示价为实际启用的计费规则基础价乘以对应分组倍率。

- 固定倍率模型使用实际模型、输出及缓存倍率。
- 动态计费模型优先读取动态表达式，固定倍率表不参与展示。卡片列出所有档位的最低到最高价格；展开明细显示每档折后价格、可解析的上下文条件，以及表达式定义的峰谷时间和时区。
- 无法可靠解析的表达式或请求附加倍率显示“按请求条件计费”，不回退到旧固定价格。
- 默认缓存写入倍率与结算一致（未配置时 1.25），Claude 的 1 小时缓存写入价单独披露。未单独计价的维度不标为免费。
- 分组倍率表示相对于站内计费基础价的倍率，不宣称为官方售价折扣；不再划线展示旧固定倍率价。

这些改动只更新当前价格披露，不修改实际扣费配置，不重算历史账单。
